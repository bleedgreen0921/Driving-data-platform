# 产品范围

使用既有 nuScenes mini，完成质量检查、分布分析、关键帧筛选、图片与标注核对及可追溯清单导出。关键帧是筛选粒度，场景提供上下文；不计算轨迹速度，不做点云三维渲染。

支持以已登记关键帧相机图片为单位的多模态图文检索，操作包括文本搜图和图片搜图。本地 llama 与外部 embedding 后端使用独立、可追溯的向量空间及向量版本，关联既有业务 generation。可用语言取决于实际模型能力；验收仅说明实际使用的样本，不设中文限定。

结构化筛选包含地点、UTC 起止时间、单个精确类别及多个必需通道，条件取交集。通道表示关键帧登记媒体；文件是否校验由 `capabilities.original_media` 说明。没有已校验原图时禁止媒体接口和图文检索，但仍可查询登记信息、标注、分布和筛选结果。查询、详情、媒体及导出绑定同一个业务 generation；检索同时绑定固定向量版本。

临时图片上传只用于本次编码查询，不登记媒体、不入库、不落上传文件。原始媒体只读保存在仓库外，在线服务不修改数据集。

页面明确显示版本、空结果、未建向量、繁忙和依赖失败。工程正确性、样本相关性与容量分别验收，不把有限测试通过等同于全部实际可用。

实现及最新验证范围以[当前状态](current-status.md)为准。部署见[运行说明](deployment.md)，外部协议与空间见[后端说明](embedding-backends.md)，数据契约见[运行证据](run-evidence.md)。
